# Derived empirical outputs

These tables are frozen, non-identifying outputs from the research pipeline. They are the inputs to the two public notebooks.

| File | Contents |
| --- | --- |
| `h1_primary_result.csv` | Primary coefficient and alternative inference results |
| `h1_specification_progression.csv` | Same-support fixed-effect and control sequence |
| `h1_sign_randomization_summary.csv` | Four sign-randomization designs |
| `h1_sign_randomization_draws.csv.gz` | 199,996 coefficient draws used for the null plots |
| `h1_robustness_checks.csv` | Peer, weighting, and influence checks |
| `h1_dynamic_response.csv` | Common-support response estimates across horizons |

No row identifies a prediction-market contract, firm, or trading date.
