\# Data Policy



This public repository is a documented companion to a larger research pipeline.



It intentionally excludes:



\- Raw Databento, WRDS/TAQ, Polymarket, and Kalshi data

\- Vendor-restricted or licensed datasets

\- API credentials, tokens, and local configuration files

\- Full manual-review inputs and audit ledgers

\- Large intermediate Parquet files, caches, and generated archives



The repository will include a small public-safe example dataset or synthetic demonstration data where needed to illustrate the pipeline.



The code and documentation are designed to show the research architecture, validation logic, and selected reproducible analyses without redistributing restricted data.
