\# Prediction-Market Price Discovery



A reproducible research-engineering companion project studying whether probability revisions in prediction markets are reflected in economically linked equity prices after equity-market closures.



\## What this repository demonstrates



\- Multi-source financial-data engineering with prediction-market and equity-market data

\- Data-quality controls, canonicalization, and reproducibility checks

\- Human-reviewed event–firm mappings and sign validation

\- Hard-closure price-discovery analysis and selected robustness checks



\## Data policy



This repository intentionally excludes raw vendor data, API credentials, confidential research inputs, and large intermediate datasets. It provides a documented, runnable public companion to a larger research pipeline.
